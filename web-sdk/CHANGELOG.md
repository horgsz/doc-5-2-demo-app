# Changelog for Idverse web sdk

## [1.1.1]
 - Bugfix: Resolve rare video corruption in document scan recordings.

## [1.1.0]
 - Improvements to injected video detection.
 - Updated default video recording codec and bitrate.
 - Add optional `transparent-face-scan-backdrop` attribute to <idv-sdk-web> that removes the dark overlay behind the face scan modal so the underlying page remains visible during liveness capture.
