# IDVerse Core Web SDK

A high-performance identity verification kit. Automate your identity verification process with our next generation document and liveness video capture.

* **Automated Document Capture:** Intelligent frame selection, perspective correction, and real-time quality validation.
* **Document Classification & OCR:** Instant document type identification and data extraction, with global document coverage. 
* **Document Fraud:** Real-time detection of digital tampering, synthetic documents and physical document anomalies.
* **Automated Liveness Capture:** Seamless, guided capture for biometric verification.
* **Liveness & Biometric Fraud:** Advanced digital and physical anti-spoofing (PAD) and proof-of-life analysis.
* **Biometric Face Matching:** High-precision matching between the identity document and liveness video.
